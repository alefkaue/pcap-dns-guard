# PCAP DNS Guard

Projeto pessoal em **C++**, desenvolvido com assistência de IA, exemplos sintéticos
e testes executáveis. Análise defensiva offline; não executa exploração nem altera o ambiente analisado.

O README em inglês contém os comandos completos de instalação, execução e testes. A saída demonstrada
está em `docs/demo-output.txt`; as decisões e limitações estão em `docs/design.md`.

Os resultados são observações para revisão. Dados inconclusivos não viram vulnerabilidades comprovadas.
Exemplos não representam experiência profissional, clientes ou análise de infraestrutura de terceiros.
